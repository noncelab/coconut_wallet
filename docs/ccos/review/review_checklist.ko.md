# 제안 기능 리뷰 체크리스트

영문 버전: [review_checklist.en.md](./review_checklist.en.md)

이 문서는 제안된 기능을 리뷰할 때 확인해야 할 기본 체크리스트예요.

## 1. 경계

- 기능이 Green / Yellow / Red 중 어디에 속하는지 명시되었는가
- 그렇게 분류한 이유가 적혀 있는가
- Red 영역을 건드리지 않는가

## 2. 안전성

- 지갑 핵심 로직을 수정하지 않는가
- 보안에 민감한 경로를 건드리지 않는가
- 새로운 개인정보 또는 보안 관련 위험 지점을 만들지 않는가

## 3. 구조

- 코코넛 월렛의 테마 / 토큰 / 기본 UI 규칙을 따르는가
- 기여자가 수정할 수 있는 범위 안에서 설명 가능한가
- 공식 경로와 폴더 구조를 따르는가

## 4. 테스트

- 기능에 맞는 테스트가 추가되었는가
- 테스트를 추가하지 않았다면 이유가 분명하게 적혀 있는가
- 변경된 기능을 어떻게 수동 검증했는지 확인할 수 있는가

## 5. 문서

- 필요한 문서 업데이트가 같이 포함되었는가
- 기여 시작 문서의 내용과 충돌하지 않는가

## 6. 범위

- Yellow 기능이라면 사전 검토 기록이 있는가
